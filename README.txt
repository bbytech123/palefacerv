UPLOAD
1. Extract this ZIP.
2. Upload index.html, styles.css, and favicon.svg to the root of the GitHub repository that will host the page. Upload the files, not the ZIP itself.
3. In GitHub Settings > Pages, select the desired publishing branch and /(root) folder if using branch-based publishing.
4. Preserve any existing CNAME file or custom-domain settings. No CNAME is included here, so this package will not change domain configuration.

The page is entirely static: no build, packages, backend, tracking, external fonts, or JavaScript required. You can double-click index.html to preview it locally. README.txt does not need to be uploaded.
